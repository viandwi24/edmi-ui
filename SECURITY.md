# Security Policy

## Supported versions

Only the latest `0.x` release of `@edmi-ui/tokens` and `@edmi-ui/registry-{react,vue,svelte}` receives security fixes.
Components are copied into your project by the shadcn CLIs, so after a fix is released re-add the affected items
(see the [Upgrading guide](https://viandwi24.github.io/edmi-ui/getting-started/upgrading/)).

## Reporting a vulnerability

Please do not open a public issue. Report it privately with GitHub Security Advisories: open the
[Security tab of viandwi24/edmi-ui](https://github.com/viandwi24/edmi-ui/security) and choose **Report a vulnerability**.

Include what is affected (item, framework, version), steps to reproduce and the impact. You can expect an
acknowledgement within a few days; a fix and advisory follow once the report is confirmed.
