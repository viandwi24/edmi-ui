# @edmi-ui/registry-react

Built [shadcn](https://ui.shadcn.com) registry JSON for Edmi UI (React). Contains only `r/*.json`; it is
published so the registry can be pinned to a version through a CDN.

```bash
bunx shadcn@latest add https://cdn.jsdelivr.net/npm/@edmi-ui/registry-react@0/r/button.json
```

See https://viandwi24.github.io/edmi-ui for docs.
