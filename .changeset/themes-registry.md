Registry themes for every base x accent: `theme-stone-green`, `theme-stone-ocean`, `theme-slate-green`, `theme-slate-ocean` (`registry:theme`, complete light + dark color tokens, replace `:root`/`.dark` on install; radius is left alone). Bases and accents are auto-discovered from `src/base/*.css` and `src/themes/*.css`. `@edmi-ui/tokens/css-vars` gains `listBases`, `listThemes`, `composeCssVars`, `themeItemCssVars` and `themeToCss`. Docs get a Themes customizer page and a runtime theming guide.
