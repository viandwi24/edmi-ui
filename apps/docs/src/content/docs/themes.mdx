Edmi themes work like shadcn's: four independent knobs, all plain CSS variables. **Base color** sets the
neutrals, **theme** sets the accent, **radius** scales every corner, and **mode** is light or dark. Stone ·
Green is the default; Slate and Ocean are examples of how to customize. The preview below is scoped, so the
docs chrome keeps its own theme.

<ThemesPlayground />

Every base and theme combination is also a registry item (`theme-stone-green`, `theme-stone-ocean`,
`theme-slate-green`, `theme-slate-ocean`). See [Theming](/edmi-ui/theming/) for how they work, how to switch
at runtime and how to add your own base or theme.
