## Raised ✦

Flat by default. Pass `raised` for the one-step 3D look (on `SelectTrigger` (the popup stays flat)).

<ComponentDemo name="select" demo="select-raised" />

## API
| Prop | Type | Default |
| --- | --- | --- |
| SelectTrigger size | `sm \| default` | `default` |
| SelectContent alignItemWithTrigger | `boolean` | `true` |
| value / defaultValue | `string` | none |
| `raised` | `boolean` | `false` |

## ✦ Edmi additions
- Flat popover surface; `raised` affects only the trigger; highlighted item uses the accent fill.

## Vue / Svelte differences
- **Svelte**: the root requires `type="single"` (or `"multiple"`); React and Vue infer single selection.
