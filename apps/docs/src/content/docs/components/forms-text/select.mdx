## Elevation ✦

`elevation` on `SelectTrigger` takes sunken -1, flat, raised +1 or floating +2. The popup (`SelectContent`) takes its own `elevation` (flat by default; floating is its natural level in layered mode).

## API
| Prop | Type | Default |
| --- | --- | --- |
| SelectTrigger size | `sm \| default` | `default` |
| SelectContent alignItemWithTrigger | `boolean` | `true` |
| value / defaultValue | `string` | none |
| items (React) | `{ value, label }[]` | none |
| `SelectTrigger elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
| `SelectContent elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

## ✦ Edmi additions
- Flat popover surface; `elevation` on the trigger and on `SelectContent` are independent; highlighted item uses the accent fill.

## Vue / Svelte differences
- **React**: Base UI shows the raw `value` in `SelectValue` unless the root gets `items={[{ value, label }]}` (or `SelectValue` a render function), so pass `items` with the labels. Vue and Svelte show the selected item text automatically.
- **Svelte**: the root requires `type="single"` (or `"multiple"`); React and Vue infer single selection.
