## Elevation ✦

Fields are flat by default and sink (-1) in layered mode. `sunken` shows a soft inset well (focus swaps the edge for the ring), `raised` (+1) a bevel and `floating` (+2) a bevel with a soft drop.

<ComponentDemo name="input" demo="input-raised" />

## API
| Prop | Type | Default |
| --- | --- | --- |
| Props | `React.ComponentProps<"input">` (Base UI Input) | none |
| aria-invalid | `boolean` | `false` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

## ✦ Edmi additions
- No size prop; the state comes from `disabled` and `aria-invalid`.
- A ring halo on focus and error; the sunken level swaps its edge for the ring on focus.
