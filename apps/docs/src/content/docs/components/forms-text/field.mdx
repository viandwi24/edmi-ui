## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

A `FieldLabel` that wraps a `Field` is a choice card. `elevation` on the `FieldLabel` sets its depth (sunken -1, flat, raised +1, floating +2); a checked card keeps the ring border.

<ComponentDemo name="radio-group" demo="radio-group-elevation" />

## API
| Prop | Type | Default |
| --- | --- | --- |
| Field orientation | `vertical \| horizontal \| responsive` | `vertical` |
| FieldLegend variant | `legend \| label` | `legend` |
| FieldError errors | `Array<{ message?: string }>` | none |
| FieldLabel elevation ✦ | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

## ✦ Edmi additions
- Choice-card labels (a FieldLabel wrapping a Field) highlight with the ring border when checked; `elevation` adds depth.
