## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Same levels as Input, applied to the select box: `sunken` (-1), `flat`, `raised` (+1), `floating` (+2).

## API
| Prop | Type | Default |
| --- | --- | --- |
| size | `sm \| default` | `default` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

## ✦ Edmi additions
- `NativeSelectOption` and `NativeSelectOptGroup` wrap the native elements.
