## Elevation ✦

`elevation="raised"` raises every item. `elevation="floating"` floats the whole group as one plate (a single soft drop); the items stay raised, never one drop per item. Buttons inside can still override with their own `elevation`.

<ComponentDemo name="button-group" demo="button-group-raised" />

## API
| Prop | Type | Default |
| --- | --- | --- |
| orientation | `horizontal \| vertical` | `horizontal` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Parts: `ButtonGroup`, `ButtonGroupSeparator`, `ButtonGroupText` (`render` supported).
