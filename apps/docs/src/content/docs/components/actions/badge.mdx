## API
| Prop | Type | Default |
| --- | --- | --- |
| variant | `default \| secondary \| destructive \| outline \| ghost \| link \| brand \| warning \| info` | `default` |
| shape | `default \| pill \| number` | `default` |
| render | `ReactElement` | none |

## ✦ Edmi additions
- `brand`, `warning`, `info` variants: soft fill with a tinted border.
- `shape`: `pill` and `number` (mono, for counts).
