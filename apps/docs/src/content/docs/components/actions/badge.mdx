## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Badges keep their fill and tinted border at every level; only the edge changes: `sunken` (-1) is a soft inset, `raised` (+1) a bevel, `floating` (+2) a bevel with a small drop.

## API
| Prop | Type | Default |
| --- | --- | --- |
| variant | `default \| secondary \| destructive \| outline \| ghost \| link \| brand \| success \| warning \| info` | `default` |
| shape | `default \| pill \| number` | `default` |
| render | `ReactElement` | none |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

## ✦ Edmi additions
- `brand`, `success`, `warning`, `info` variants: soft fill with a tinted border. Use `success` for positive deltas and done states (green in every theme); `brand` follows the theme accent.
- `shape`: `pill` and `number` (mono, for counts).
