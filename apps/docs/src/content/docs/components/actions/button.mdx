## Elevation ✦

Flat by default. `elevation` adds depth: `raised` (+1) is a bevel (inner rim, top highlight, dark hairline), `floating` (+2) adds one soft drop for a hero action, `sunken` (-1) presses the button into a well (filled variants keep their colour, 8% darker). `ghost` follows the neutral faces; `link` never gets depth. Pressed sinks 1px. `auto` follows the nearest `ElevationProvider` (layered mode: filled variants resolve to raised).

## API
| Prop | Type | Default |
| --- | --- | --- |
| variant | `default \| secondary \| outline \| ghost \| destructive \| link \| brand` | `default` |
| size | `xs \| sm \| default \| lg \| icon-xs \| icon-sm \| icon \| icon-lg` | `default` |
| render | `ReactElement` | none |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

## ✦ Edmi additions
- `brand` variant (green).
- `elevation` prop: a bevel (no hard lip) that sinks 1px on press. `link` ignores it; `ghost` follows the neutral faces.
- Style links with `buttonVariants()` on a plain `<a>`.
