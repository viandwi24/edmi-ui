## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Set it on `Kbd` (not `KbdGroup`). `raised` (+1) bevels the key cap, `floating` (+2) adds a soft drop. Inside a tooltip the key stays flat.

<ComponentDemo name="kbd" demo="kbd-elevation" />

## API
| Prop | Type | Default |
| --- | --- | --- |
| className | `string` | none |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Parts: `Kbd`, `KbdGroup`.

## ✦ Edmi additions
- Flat key cap (`--muted`, 1px border, mono); `elevation` adds the bevel. Adapts inside `data-slot=tooltip-content`.
