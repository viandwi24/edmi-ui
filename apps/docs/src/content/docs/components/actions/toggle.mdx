## Elevation ✦

Flat by default. Raised (+1) and floating (+2) apply to `outline` toggles as a whole; a default toggle only shows depth while it is ON (pressed in). Sunken is not supported.

<ComponentDemo name="toggle" demo="toggle-raised" />

## API
| Prop | Type | Default |
| --- | --- | --- |
| variant | `default \| outline` | `default` |
| size | `sm \| default \| lg` | `default` |
| pressed / defaultPressed | `boolean` | `false` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

## ✦ Edmi additions
- Pressed state: accent fill; with `elevation` raised or floating it also sinks with an inner shadow. `outline` raised uses the neutral bevel face, also for toggle-group items.
