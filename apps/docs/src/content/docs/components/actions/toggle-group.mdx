## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

`elevation` on the group flows to every item. For `variant="segmented"` only the ON item rises (the track never bevels). Raised (+1) and floating (+2) are equivalent on items.

## API
| Prop | Type | Default |
| --- | --- | --- |
| variant | `default \| outline \| segmented` | `default` |
| size | `sm \| default \| lg` | `default` |
| spacing | `number` | `2` |
| orientation | `horizontal \| vertical` | `horizontal` |
| multiple | `boolean` | `false` |
| value / defaultValue | `string[]` | none |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

## ✦ Edmi additions
- `variant="segmented"`: flat track with a tab-active fill (for single selection such as ranges).
