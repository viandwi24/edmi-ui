## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. On `PopoverContent`, `raised` (+1) adds the bevel and `floating` (+2) the bevel plus one soft drop (the natural level in layered mode).

## API
| Prop | Type | Default |
| --- | --- | --- |
| `PopoverContent side` | `top \| right \| bottom \| left` | `bottom` |
| `PopoverContent align` | `start \| center \| end` | `center` |
| `PopoverContent sideOffset` | `number` | `6` |
| `PopoverTrigger render` | `ReactElement` | none (Base UI, replaces `asChild`) |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Parts: `Popover`, `PopoverTrigger`, `PopoverContent`, `PopoverHeader`, `PopoverTitle`, `PopoverDescription`.

## ✦ Edmi additions
- Flat by default; `elevation` adds the bevel / drop. Solid `--popover` surface with a 1px border.
