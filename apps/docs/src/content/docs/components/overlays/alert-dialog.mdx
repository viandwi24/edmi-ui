## Raised ✦

Flat by default. Pass `raised` for the one-step 3D look (on `AlertDialogContent`).

## API
| Prop | Type | Default |
| --- | --- | --- |
| `AlertDialogContent size` | `default \| sm` | `default` |
| `AlertDialogAction` | Button props | `default` variant |
| `AlertDialogCancel variant / size` | Button props | `outline` / `default` |
| `raised` | `boolean` | `false` |

Parts: `AlertDialog`, `AlertDialogTrigger`, `AlertDialogContent`, `AlertDialogHeader`, `AlertDialogMedia`, `AlertDialogTitle`, `AlertDialogDescription`, `AlertDialogFooter`, `AlertDialogCancel`, `AlertDialogAction`.

## ✦ Edmi additions
- `--overlay` scrim without blur, hard 4px strong lip. Pass `variant="destructive"` to `AlertDialogAction` for the red confirm.
