## Elevation ✦

Flat by default. On `AlertDialogContent`, `raised` (+1) adds the bevel and `floating` (+2) the bevel plus one soft drop (the natural level in layered mode).

<ComponentDemo name="alert-dialog" demo="alert-dialog-raised" />

## API
| Prop | Type | Default |
| --- | --- | --- |
| `AlertDialogContent size` | `default \| sm` | `default` |
| `AlertDialogAction` | Button props | `default` variant |
| `AlertDialogCancel variant / size` | Button props | `outline` / `default` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Parts: `AlertDialog`, `AlertDialogTrigger`, `AlertDialogContent`, `AlertDialogHeader`, `AlertDialogMedia`, `AlertDialogTitle`, `AlertDialogDescription`, `AlertDialogFooter`, `AlertDialogCancel`, `AlertDialogAction`.

## ✦ Edmi additions
- `--overlay` scrim without blur, optional bevel / drop via `elevation`. Pass `variant="destructive"` to `AlertDialogAction` for the red confirm.
