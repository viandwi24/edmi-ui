## API
| Prop | Type | Default |
| --- | --- | --- |
| `TooltipContent side` | `top \| right \| bottom \| left` | `top` |
| `TooltipContent sideOffset` | `number` | `6` |
| `TooltipProvider delay` | `number` (ms) | `0` |

Parts: `TooltipProvider`, `Tooltip`, `TooltipTrigger`, `TooltipContent`. A disabled trigger must be wrapped in a `span`.
