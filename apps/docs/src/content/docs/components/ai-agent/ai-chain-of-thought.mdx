## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| ChainOfThought | `open`, `defaultOpen`, `onOpenChange` | controlled / uncontrolled open state | `defaultOpen = false` |
| ChainOfThoughtHeader | `children` | label | `Chain of thought` |
| ChainOfThoughtStep | `icon` | `ReactNode` (an `IconPlaceholder` or svg) | small dot |
| ChainOfThoughtStep | `label`, `description` | `ReactNode` | |
| ChainOfThoughtStep | `status` | `complete \| active \| pending` | `complete` |
| ChainOfThoughtSearchResult | Badge props | secondary pill | |
| ChainOfThoughtImage | `caption` | `string` | |

## ✦ Edmi additions
- `icon` takes an element instead of an icon component, so it follows the consumer's `iconLibrary`.
- Statuses: `active` shows a `--brand` icon and a foreground label (pair it with `Shimmer`), `pending` is faint.
- A 1px `--border` line joins the step icons and stops after the last step.
