## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| Task | `open`, `defaultOpen`, `onOpenChange` | collapsible state | `defaultOpen = true` |
| TaskTrigger | `title` | `string` | |
| TaskItem | `status` | `pending \| in-progress \| completed \| error` | none |
| TaskItemFile | | mono file chip | |

## ✦ Edmi additions
- `TaskItem` `status` ✦ adds a leading status icon: spinner while in progress, struck-through text when completed, destructive text on error.
- `TaskItemFile` carries a file icon; the chip is never struck through.
