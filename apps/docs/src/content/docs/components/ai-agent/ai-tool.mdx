## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| Tool | `raised` | `boolean` | `false` |
| Tool | `open`, `defaultOpen`, `onOpenChange` | collapsible state | closed |
| ToolHeader | `type`, `state`, `title`, `toolName` | AI SDK `ToolUIPart` / `DynamicToolUIPart` fields | |
| ToolInput | `input` | `unknown` (shown as JSON) | |
| ToolOutput | `output`, `errorText` | `unknown`, `string` | |
| getStatusBadge | `state` | returns the badge for one of the seven AI SDK states | |

## ✦ Edmi additions
- One badge colour per state: pending (secondary), running (info), awaiting approval (warning), responded (secondary), completed (success), denied (outline), error (destructive).
- The parameters and result render as plain mono blocks on `--muted` (the error block on `--destructive-soft`), so the item does not depend on `ai-code-block`.
- `raised` ✦ gives the card the one-step 3D look.
