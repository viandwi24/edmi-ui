## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

The request is a flat warning alert; `elevation` goes to the action buttons (flat, raised +1, floating +2, sunken -1 like a Button) and each `ConfirmationAction` can override it.

## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| Confirmation | `approval`, `state` | AI SDK tool approval and `ToolUIPart["state"]` | |
| Confirmation | `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` (the action buttons inherit it) | `"auto"` |
| Confirmation | `icon` | `ReactNode` | shield |
| ConfirmationTitle | | request title (put `ConfirmationRequest` / `Accepted` / `Rejected` inside) | |
| ConfirmationDescription | | muted second line, only while the request is open | |
| ConfirmationActions | | row of actions, only while the request is open | |
| ConfirmationAction | `elevation`, `variant`, `size` | Button props | `size="sm"` |

## ✦ Edmi additions
- The open request is a `warning` alert; once answered it collapses to a plain status line (green check when approved, muted cross when rejected).
- `ConfirmationDescription` ✦ is the muted line under the title.
- `elevation` ✦ is passed to every `ConfirmationAction` (each can override it); the alert itself stays flat.
