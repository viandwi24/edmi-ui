## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| QueueSection | `open`, `defaultOpen` | collapsible state | `defaultOpen = true` |
| Queue | `variant` ✦ | `"card" \| "flat"` | `"card"` |
| QueueSectionLabel | `label`, `count`, `icon`, `chevron` ✦ | label, number badge, optional icon, collapse chevron | `chevron = true` |
| QueueItemAvatar, QueueItemStatus ✦ | | leading and trailing slots of an item row | |
| QueueItemIndicator, QueueItemContent, QueueItemDescription | `completed` | `boolean` | `false` |
| QueueItemAction | Button props | ghost `icon-xs`, revealed on hover or focus | |
| QueueItemImage, QueueItemFile | | attachment thumbnails | |

## Flat ✦

`variant="flat"` drops the card border, fill and padding (the AI home board). Hide the chevron with `chevron={false}` on `QueueSectionLabel`, and use `QueueItemAvatar` / `QueueItemStatus` for the leading avatar and trailing age or status.

## ✦ Edmi additions
- The count is a number badge next to the label, and a section that follows another gets a divider.
- Item actions appear on hover and keyboard focus.
- The types `QueueMessage` and `QueueTodo` are exported for AI SDK data.
