## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| Plan | `isStreaming` | `boolean` (title and description shimmer) | `false` |
| Plan | `raised` | `boolean` | `false` |
| Plan | `open`, `defaultOpen`, `onOpenChange` | collapsible state | closed |
| PlanTitle, PlanDescription | `children` | `string` | |
| PlanTrigger | Collapsible trigger | ghost icon button | |
| PlanFooter | | card footer | |

## ✦ Edmi additions
- `raised` ✦ goes to the Card; pass `raised` to the footer `Button`s as well for the full look.
- The footer sits on the shell colour, like every Card footer in Edmi.
