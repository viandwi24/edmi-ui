## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| Reasoning | `isStreaming` | `boolean` | `false` |
| Reasoning | `open`, `defaultOpen`, `onOpenChange` | controlled / uncontrolled open state | `defaultOpen = isStreaming` |
| Reasoning | `duration` | `number` (seconds; measured automatically while `isStreaming` flips) | |
| ReasoningTrigger | `getThinkingMessage` | `(isStreaming, duration) => ReactNode` | shimmer `Thinking…`, then `Thought for N seconds` |
| ReasoningContent | `children` | `string` (rendered as markdown) | |

## ✦ Edmi additions
- Opens on its own while `isStreaming`, closes one second after streaming ends and keeps the measured duration as the label.
- The content sits behind a 2px `--border` rule; the label is muted until hovered.
- The shimmer sweep is a `--foreground` highlight over `--muted-foreground`, so it reads in light and dark.
