## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. On `Menubar`, `raised` (+1) adds the bevel to the bar and `floating` (+2) a soft drop. The menus below it follow `DropdownMenuContent` (flat, or `elevation` on the content).

## API
| Prop | Type | Default |
| --- | --- | --- |
| `MenubarItem variant` | `default \| destructive` | `default` |
| `MenubarItem inset` | `boolean` | `false` |
| `MenubarContent align` | `start \| center \| end` | `start` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Parts: `Menubar`, `MenubarMenu`, `MenubarTrigger`, `MenubarContent`, `MenubarGroup`, `MenubarLabel`, `MenubarItem`, `MenubarCheckboxItem`, `MenubarRadioGroup`, `MenubarRadioItem`, `MenubarSeparator`, `MenubarShortcut`, `MenubarSub`, `MenubarSubTrigger`, `MenubarSubContent`.

## ✦ Edmi additions
- Menus reuse the Dropdown Menu recipe (`data-[highlighted]`); the open trigger stays highlighted.
