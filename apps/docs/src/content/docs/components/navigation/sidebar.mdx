## API
| Prop | Type | Default |
| --- | --- | --- |
| `SidebarProvider defaultOpen` / `open` / `onOpenChange` | `boolean` / `boolean` / `(open) => void` | `true` |
| `Sidebar side` | `left \| right` | `left` |
| `Sidebar variant` | `sidebar \| floating \| inset` | `sidebar` |
| `Sidebar collapsible` | `offcanvas \| icon \| none` | `offcanvas` |
| `SidebarMenuButton isActive` | `boolean` | `false` |
| `SidebarMenuButton size` | `default \| sm \| lg` | `default` |
| `SidebarMenuButton tooltip` | `string \| TooltipContent props` | none |
| `SidebarMenuButton render` | `ReactElement` | `<button>` (Base UI, replaces `asChild`) |
| `SidebarMenuAction showOnHover` | `boolean` | `false` |

`useSidebar()` returns `{ state, open, setOpen, openMobile, setOpenMobile, isMobile, toggleSidebar }`. Cmd/Ctrl+B toggles. On mobile the sidebar opens as a Sheet (`use-mobile` hook).

Parts: `SidebarProvider`, `Sidebar`, `SidebarHeader`, `SidebarContent`, `SidebarFooter`, `SidebarGroup`, `SidebarGroupLabel`, `SidebarGroupAction`, `SidebarGroupContent`, `SidebarMenu`, `SidebarMenuItem`, `SidebarMenuButton`, `SidebarMenuAction`, `SidebarMenuBadge`, `SidebarMenuSkeleton`, `SidebarMenuSub`, `SidebarMenuSubItem`, `SidebarMenuSubButton`, `SidebarInput`, `SidebarSeparator`, `SidebarInset`, `SidebarRail`, `SidebarTrigger`.

## ✦ Edmi additions
- Floating and inset variants use a 1px border only (flat).
- Menu badges use the soft brand fill with a tinted border, mono numerals.
- Menu buttons are 32px tall with 7px radius; the active row uses `--sidebar-accent`.

## Vue / Svelte differences
- **Vue**: the `use-mobile` hook is not shipped (skipped). `SidebarProvider` uses `useMediaQuery` from `@vueuse/core` instead.
