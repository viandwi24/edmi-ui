## Raised ✦

Flat by default. Pass `raised` for the one-step 3D look (on `Pagination`, applies to the active link).

<ComponentDemo name="pagination" demo="pagination-raised" />

## API
| Prop | Type | Default |
| --- | --- | --- |
| `PaginationLink isActive` | `boolean` | `false` |
| `PaginationLink size` | Button sizes | `icon` |
| `PaginationPrevious text` / `PaginationNext text` | `string` | `Previous` / `Next` |
| `raised` | `boolean` | `false` |

Parts: `Pagination`, `PaginationContent`, `PaginationItem`, `PaginationLink`, `PaginationPrevious`, `PaginationNext`, `PaginationEllipsis`.

## ✦ Edmi additions
- Links are Edmi Buttons: active page is `outline`, others `ghost`.
