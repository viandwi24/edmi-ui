## API
| Prop | Type | Default |
| --- | --- | --- |
| `NavigationMenu align` | `start \| center \| end` | `start` |
| `NavigationMenuLink href` / `render` | `string` / `ReactElement` | none |
| `navigationMenuTriggerStyle()` | cva | trigger classes for plain links |

Parts: `NavigationMenu`, `NavigationMenuList`, `NavigationMenuItem`, `NavigationMenuTrigger`, `NavigationMenuContent`, `NavigationMenuLink`, `NavigationMenuIndicator`, `NavigationMenuPositioner`.
