## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| AudioPlayer | `className`, `style` | merged into the media-chrome controller (`--media-*` variables can be overridden in `style`) | |
| AudioPlayerElement | `src` or `data` | `string`, or an AI SDK speech `audio` result | |
| AudioPlayerSeekBackwardButton, AudioPlayerSeekForwardButton | `seekOffset` | `number` (seconds) | `10` |
| other parts | | media-chrome element props | |

## ✦ Edmi additions
- The player is a `--card` surface with a 1px border; play is a 36px round primary button, seek and mute are ghost icon buttons.
- Times are mono and tabular; the time range fills with `--brand` over a `--muted` track.
- Deviation from the board: the board draws a waveform for the time range; the real component uses the media-chrome range (a waveform needs decoded audio).

## Framework notes
- Vue and Svelte use the `<media-*>` custom elements directly (`seek-offset` / `seekOffset` prop on the seek buttons). In Svelte the root registers media-chrome on mount.
