## API
| Prop | Type | Default |
| --- | --- | --- |
| `state` | `idle \| listening \| thinking \| speaking \| asleep` | `idle` |
| `variant` | `obsidian \| mana \| opal \| halo \| glint \| command` | `obsidian` |
| `className` | size and layout of the canvas | `size-16` |
| `onLoad`, `onLoadError`, `onReady`, `onPlay`, `onPause`, `onStop` | Rive callbacks | |

## ✦ Edmi additions
- Dynamic-color variants follow light and dark, including a scoped `.dark` subtree (not only `<html>`).
- Deviation from the board: the board shows tinted static orbs in `--brand` / `--chart-*`; the Rive files are fixed artwork, so only the monochrome variants recolor.

## Framework notes
- Vue and Svelte use `@rive-app/webgl2` directly with the same artwork and states; callbacks are emits in Vue (`load`, `loadError`, `ready`, `play`, `pause`, `stop`) and `on*` props in Svelte.
