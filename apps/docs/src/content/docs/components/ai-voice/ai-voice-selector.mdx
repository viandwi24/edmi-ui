## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| VoiceSelector | `value`, `defaultValue`, `onValueChange` | voice id | |
| VoiceSelector | `open`, `defaultOpen`, `onOpenChange` | `boolean` | `false` |
| VoiceSelectorTrigger | `render` | the visible trigger, e.g. `<Button variant="outline" />` | |
| VoiceSelectorContent | `title` | `ReactNode` (screen reader title) | `Voice Selector` |
| VoiceSelectorItem | `value`, `onSelect` | the selected item shows the check; without `onSelect` it sets the value and closes | |
| VoiceSelectorPreview | `playing`, `loading`, `onPlay` | `boolean`, `boolean`, `() => void` | |
| VoiceSelectorGender, VoiceSelectorAccent | `value` | text fallback when no `children` | |

## ✦ Edmi additions
- `VoiceSelectorDetails` and `VoiceSelectorHeader` lay out the two-line row (name + attributes, then description).
- Gender and accent render as muted text separated by `VoiceSelectorBullet` (middle dot), as on the board, not as icons and flags.

## Framework notes
- Vue: `v-model:value` / `v-model:open`, trigger via `as-child`; selecting always sets the value and closes (extra `@select` runs after). Svelte: `bind:value`, trigger via the `child` snippet; passing `onSelect` replaces the default select behaviour, as in React.
