## API
| Prop | Type | Default |
| --- | --- | --- |
| `onTranscriptionChange` | `(text: string) => void` | |
| `onAudioRecorded` | `(blob: Blob) => Promise<string>` (MediaRecorder fallback: return the transcript) | |
| `lang` | `string` | `en-US` |
| `variant`, `size` | Button props | `outline`, `icon` |
| `raised` | `boolean` | `false` |

## ✦ Edmi additions
- States follow the board: outline default, `--brand` fill with a solid soft ring and pulsing outlines while listening, spinner while processing, 45% opacity when disabled.

## Framework notes
- Vue: `transcriptionChange` event and `on-audio-recorded` prop. Svelte: `onTranscriptionChange` and `onAudioRecorded` props. The mic icon in Vue is `AudioLinesIcon` (the shadcn-vue icon map has no mic icon; with the Phosphor default it renders a microphone).
