## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. `elevation` on `Questionnaire` applies to every choice card and the text input: `sunken` (-1) wells, `raised` (+1) the bevel, `floating` (+2) bevel plus drop. A checked option keeps its ring.

## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| Questionnaire | items | `{ name, choices?, required? }[]` | none |
| Questionnaire | shortcuts | `letters \| numbers` | none |
| Questionnaire | onSubmit | form event handler | none |
| QuestionnaireItem | name, multiple, required, invalid | | |
| QuestionnaireChoice | value | `string` | required |
| QuestionnairePrevious, Skip, Next, Submit | size, variant | Button props | |
| Questionnaire | elevation | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Put a `QuestionnaireInput` inside an item next to its choices for an "Other: ____" answer: typing selects the input and clears the choices, picking a choice selects it again (the typed text is kept but no longer submitted).

Built on `@shadcn/react/questionnaire`.

## ✦ Edmi additions
- Choices and the freeform input share one 48px row height. The shortcut key sits on the left (brand when selected) and the selected row gets a ring.
- Previous is a ghost button, matching the board.
