## Elevation ✦

Flat by default. `elevation` on `BubbleReactions` (`raised` +1 or `floating` +2) bevels every `BubbleReaction` chip; the `active` tint is kept. A chip can override it with its own `elevation`.

## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| Bubble | variant | `default \| secondary \| muted \| tinted \| outline \| ghost \| destructive` | `default` |
| Bubble | align | `start \| end` | `start` |
| BubbleContent | render | `ReactElement` (button or link bubbles) | none |
| BubbleReactions | side | `top \| bottom` | `bottom` |
| BubbleReactions | align | `start \| end` | `end` |
| BubbleGroup | stacks bubbles | `div` props | none |
| BubbleReactions | elevation | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

## ✦ Edmi additions
- `BubbleReaction` (`active`): a solid floating chip with a 1px border and no ring; the active chip is brand-tinted.
- `tinted` and `destructive` use the soft brand and destructive tokens; `ghost` keeps its vertical padding so avatars line up.

## Vue / Svelte differences
- **Svelte**: `BubbleContent` has no `render` prop. Pass `href` to render an `<a>`, or `as="button"` for a `<button>`.
