## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. `elevation` is forwarded to the card: `sunken` (-1) a soft inset well, `raised` (+1) the bevel, `floating` (+2) the bevel plus one soft drop. In a layered `ElevationProvider` the card resolves to its role default (raised).

## API
| Part | Props | Notes |
| --- | --- | --- |
| `FeedPost` | `Card` props | Root card (18px padding). |
| `FeedPostHeader` | `name, handle?, time?, avatarSrc?, initials?, actions?` | Avatar + name line; `actions` defaults to a ghost more button. |
| `FeedPostContent` | `p` props | Post body. |
| `FeedPostIndex` | `title, description?, icon?, action?` | Attached index as an outline sm Item. |
| `FeedPostFooter / FeedPostStat` | div / span props | Muted stat row. |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
