## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| `IndexRow` | `index` | `{ name, symbol, avatars, tags?, owner, price, change, value, count, spark?, href? }` | required |
| | `rank` ✦ | `number \| string` | none (no rank column) |
| | `delta` ✦ | `"text" \| "pill"` | `"text"` |
| `IndexRowHeader` | `labels` | `{ name?, owner?, price?, change?, value?, count?, trend? }` column labels (Svelte values may be snippets) | `Name`, `Owner`, `Price`, `Change`, `Value`, `Count`, `Trend` |
| | `rank` ✦ | `boolean` | `false` |
| `Sparkline` | `data` | `number[]` | required |
| | `tone` | `"up" \| "down"` | last vs first |
| | `width` / `height` | `number` | `88` / `28` |

Place `IndexRowHeader` in `TableHeader` and `IndexRow` in `TableBody`; numeric columns are mono and right-aligned.

## Ranked, pill delta ✦

Leaderboard style: a leading mono rank column and the change as a soft tinted pill.

## Elevation ✦

Flat only: a table row has no depth. Put the table in a `Card` (flat, or raised for a featured table) to give it a surface.

## ✦ Edmi additions
- `Sparkline` is exported on its own.
