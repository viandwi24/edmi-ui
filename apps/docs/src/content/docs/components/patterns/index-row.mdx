## API
| Prop | Type | Default |
| --- | --- | --- |
| `IndexRow index` | `{ name, symbol, tokens, tags?, creator, price, change, aum, holders, spark?, href? }` | required |
| `IndexRow rank` ✦ | `number \| string` | none (no rank column) |
| `IndexRow delta` ✦ | `"text" \| "pill"` | `"text"` |
| `IndexRowHeader` | `TableRow` props | |
| `IndexRowHeader rank` ✦ | `boolean` | `false` |
| `Sparkline data` | `number[]` | required |
| `Sparkline tone` | `"up" \| "down"` | last vs first |

Place `IndexRowHeader` in `TableHeader` and `IndexRow` in `TableBody`; numeric columns are mono and right-aligned (§4.10).
