## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. `elevation` raises only the active row: `raised` (+1) adds the bevel, `floating` (+2) the bevel plus one soft drop.

## API
| Prop | Type | Default |
| --- | --- | --- |
| `symbol` / `price` / `change` | `string` | required |
| `color` | CSS color | `var(--chart-1)` |
| `letter` | `string` | first letter of `symbol` |
| `active` | `boolean` | `false` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Renders an `<a>`; pass `href` and other anchor props.

## ✦ Edmi additions
- Uses the `--sidebar-*` tokens, so it fits inside the Sidebar block.
