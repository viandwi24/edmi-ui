## API
| Prop | Type | Default |
| --- | --- | --- |
| `symbol` / `price` / `change` | `string` | required |
| `color` | CSS color | `var(--chart-1)` |
| `letter` | `string` | first letter of `symbol` |
| `active` | `boolean` | `false` |
| `raised` | `boolean` | `false` |

Renders an `<a>`; pass `href` and other anchor props.
