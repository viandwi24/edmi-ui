## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. The column is a sunken well. `elevation` on the column flows to every `KanbanItem` card (items may override): `raised` (+1) bevel, `floating` (+2) bevel plus drop.

## API

| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| `KanbanColumn` | `title` | `ReactNode` (Vue/Svelte: `string`) | required |
|  | `meta` | same as `title`; right header meta, e.g. `1/3` | none |
|  | `elevation` ✦ | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
|  | `…props` | `div` props, sunken container 282px wide |  |
| `KanbanItem` | `title` | `ReactNode` (Vue/Svelte: `string`) | required |
|  | `description` | same as `title` | none |
|  | `icon` | React `ReactNode`; Vue slot `icon`; Svelte `icon` snippet | none |
|  | `action` | React `ReactNode`; Vue slot `action`; Svelte `action` snippet | arrow up-right |
|  | `disabled` | `boolean`; dims to 60% | `false` |
|  | `elevation` ✦ | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
