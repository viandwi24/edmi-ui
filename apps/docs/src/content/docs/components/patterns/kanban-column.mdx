## Elevation ✦

Flat by default. The column is a sunken well. `elevation` on the column flows to every `KanbanItem` card (items may override): `raised` (+1) bevel, `floating` (+2) bevel plus drop.

<ComponentDemo name="kanban-column" demo="kanban-column-raised" />

## API
| Part | Props | Notes |
| --- | --- | --- |
| `KanbanColumn` | `title, meta?` | Sunk container, 282px wide. |
| `KanbanItem` | `title, description?, icon?, action?, disabled?` | Card row; `disabled` dims to 60%. |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
