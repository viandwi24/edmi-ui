## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. `elevation` sets the depth of the bar; `raised` (+1) and `floating` (+2) also raise the mark, the active nav pill (only the active pill rises) and the buttons. In a layered `ElevationProvider` the bar is a raised surface and its controls follow their own roles.

## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| `AppHeader` | `logo` / `name` / `href` | as `SiteHeader` (`name` is not rendered when empty) | none / none / `"/"` |
| | `items` | `{ label, href }[]` | `[]` |
| | `active` | `string` (`href` of the active pill) | none |
| | `search` | `boolean` | `true` |
| | `searchPlaceholder` / `shortcut` | `string` | `"Search"` / `"⌘K"` |
| | `network` | secondary button label, e.g. a network or workspace (React `string`, Vue `string` or `network` slot, Svelte `string \| Snippet`); empty hides it | none |
| | `connectLabel` | `ReactNode` (Vue `connect-label` slot, Svelte `string \| Snippet`) | `"Connect"` |
| | `onConnect` / `onNetworkClick` | `() => void` (Vue emits `connect` / `network-click`) | none |
| | `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
| `AppHeaderNavItem` | `active`, `elevation` | exported for custom navs | |

## ✦ Edmi additions
- Nav pills stand alone (no track), active pill is `--tab-active` + 1px border (the `pills` look); with `elevation="raised"` it becomes a raised secondary button.
