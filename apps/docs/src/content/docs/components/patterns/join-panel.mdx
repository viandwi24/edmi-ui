## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. `elevation` is forwarded to the card (`sunken` -1, `raised` +1, `floating` +2); an explicit `raised` or `floating` also raises the tabs, quick-amount chips and the join button, `flat` and `sunken` keep them flat.

## API
| Prop | Type | Default |
| --- | --- | --- |
| `label` | `ReactNode` | `"Amount"` |
| `currency` | `string` | `"USDC"` |
| `amount` / `defaultAmount` | `string` | `""` |
| `onAmountChange` | `(value: string) => void` | none |
| `onMax` / `onJoin` | `() => void` | none |
| `rows` | `{ label, value }[]` (values mono) | `[]` |
| `joinLabel` | `ReactNode` | `"Join"` |
| `disabled` | `boolean` | `false` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
| `tabs` ✦, `tab` / `defaultTab`, `onTabChange` | `{ value, label }[]` mode tabs (Join / Redeem) | none |
| `quickAmounts` ✦ | `{ label, value? }[]` chips; no `value` calls `onMax` | none |
| `footnote` ✦ | `ReactNode` small centred note under the action | none |
| `amountSize` ✦ | `"default" \| "lg"` | `"default"` |
| `maxLabel` ✦ | plain `Max 1,240` text instead of the Max button | none |
