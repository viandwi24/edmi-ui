## API
| Prop | Type | Default |
| --- | --- | --- |
| `label` | `ReactNode` | `"Amount"` |
| `currency` | `string` | `"USDC"` |
| `amount` / `defaultAmount` | `string` | `""` |
| `onAmountChange` | `(value: string) => void` | none |
| `onMax` / `onJoin` | `() => void` | none |
| `rows` | `{ label, value }[]` (values mono) | `[]` |
| `joinLabel` | `ReactNode` | `"Join"` |
| `disabled` | `boolean` | `false` |
| `raised` | `boolean` | `false` |
