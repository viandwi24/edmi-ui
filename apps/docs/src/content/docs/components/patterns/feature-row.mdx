## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. `elevation` is forwarded to the card: `sunken` (-1) a soft inset well, `raised` (+1) the bevel, `floating` (+2) the bevel plus one soft drop. In a layered `ElevationProvider` the card resolves to its role default (raised).

## API

| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| `FeatureRow` | `index` | React `ReactNode`; Vue slot `index` (prop `string \| number` as fallback); Svelte `string \| number \| Snippet` | required |
|  | `title` | React `ReactNode`; Vue slot `title` (string prop as fallback); Svelte `string \| Snippet` | required |
|  | `icon` | React `ReactNode`; Vue slot `icon`; Svelte `icon` snippet | plus |
|  | `children` | Expandable content (Vue default slot, Svelte `children`). With content the 56px row becomes a Collapsible and the plus rotates to a cross | none |
|  | `elevation` ✦ | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
