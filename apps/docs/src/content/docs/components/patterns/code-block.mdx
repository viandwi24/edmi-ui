## API
| Part | Props | Notes |
| --- | --- | --- |
| `CodeBlock` | `code, title?, highlightLines?, copyable=true, onCopy?` | Plain mono `pre` (no syntax highlighting, no extra dependency). Copy button shows a check for 1.5s. |
| `raised` | `boolean` | `false` |
