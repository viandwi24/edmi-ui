## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. `elevation` is forwarded to the card: `sunken` (-1) a soft inset well, `raised` (+1) the bevel, `floating` (+2) the bevel plus one soft drop. In a layered `ElevationProvider` the card resolves to its role default (raised).

## API

| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| `CodeBlock` | `code` | `string` | required |
|  | `title` | React `ReactNode`; Vue `string` or slot `title`; Svelte `string \| Snippet` | none |
|  | `highlightLines` | `number[]` (1-based) | none |
|  | `copyable` | `boolean` | `true` |
|  | `onCopy` | React `onCopy(code)`; Vue `@copy`; Svelte `onCopy(code)`. Called after a successful copy | none |
|  | `elevation` ✦ | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Plain mono `pre` (no syntax highlighting, no extra dependency). The copy button shows a check for 1.5s.

## Code block vs AI code block

`code-block` is a small pattern: a card with plain mono text, a line highlight and a copy button, no dependencies. It suits docs and landing snippets. [`ai-code-block`](/edmi-ui/components/ai-code/ai-code-block/) is the full AI pack component (Shiki syntax highlighting tied to the chart tokens, language selector, composable parts). The two are separate on purpose; pick `ai-code-block` when you need real highlighting.
