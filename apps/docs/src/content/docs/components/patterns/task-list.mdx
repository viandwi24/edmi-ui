## API
| Part | Props | Notes |
| --- | --- | --- |
| `TaskList` | `tasks: {title, agent?, status}[], labels?` | Groups by `status` (`review` warning, `running` info, `completed` success) in first-appearance order; `labels` overrides badge text. |
| `raised` | `boolean` | `false` |
