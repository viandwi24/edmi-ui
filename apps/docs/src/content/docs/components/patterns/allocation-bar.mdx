## API
| Prop | Type | Default |
| --- | --- | --- |
| `segments` | `{ label, value, color? }[]` | required |
| `showLegend` | `boolean` | `true` |

Colors default to `--chart-1…5` in order.

## ✦ Edmi additions
- Bars are proportional to `value`; values need not sum to 100.
