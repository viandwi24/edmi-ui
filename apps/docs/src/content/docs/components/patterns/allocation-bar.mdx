## Elevation ✦

Flat only: the bar and legend render no surface, so there is no `elevation` prop and no elevation demo. See the [Elevation guide](/edmi-ui/getting-started/elevation/).

## API

| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| `AllocationBar` | `segments` | `{ label, value, color? }[]` | required |
|  | `showLegend` | `boolean` | `true` |

Colors default to `--chart-1…5` in order.

## ✦ Edmi additions
- Bars are proportional to `value`; values need not sum to 100.
