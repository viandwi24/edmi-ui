## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. `elevation` is forwarded to the card: `sunken` (-1) a soft inset well, `raised` (+1) the bevel, `floating` (+2) the bevel plus one soft drop. In a layered `ElevationProvider` the card resolves to its role default (raised).

## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| `AgentCard` | `name` | `string` | required |
| | `address` | `string` (mono sub line) | none |
| | `tag` | `string` (secondary badge) | none |
| | `status` | brand badge with a dot, e.g. `Live` (React `ReactNode`, Vue `status` slot, Svelte `string \| Snippet`) | none |
| | `stats` | `{ label, value }[]` (value: React `ReactNode`, Vue `stat-value` scoped slot, Svelte `string \| number \| Snippet`) | none |
| | `seed` | `string` identicon seed | `name` |
| | `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
| | `children` ✦ | React children, Vue default slot, Svelte `children` snippet: footer under the stats | none |
| `AgentIdenticon` | `seed`, `size` | token-coloured 5x5 grid, deterministic per seed | `size` 44 |

`AgentIdenticon` is intentionally not merged with the AI pack's Agent Avatar: both are seeded 5x5 identicons, but the identicon here is a full grid painted in neutral token tones (`--muted-foreground-2`, `--muted-foreground`, `--foreground-2`) on a muted tile for list cards, while Agent Avatar is a mirrored 3x5 mark tinted with a chart color. Each keeps its own look.
