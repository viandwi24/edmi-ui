## Elevation ✦

Flat by default. `elevation` is forwarded to the card: `sunken` (-1) a soft inset well, `raised` (+1) the bevel, `floating` (+2) the bevel plus one soft drop. In a layered `ElevationProvider` the card resolves to its role default (raised).

## API
| Part | Props | Notes |
| --- | --- | --- |
| `AgentCard` | `name, address?, tag?, autopilot?, stats?, seed?` | Card with identicon, secondary tag badge, brand Autopilot badge and stats. |
| `AgentIdenticon` | `seed, size=44` | Token-colored 5x5 grid, deterministic per seed. |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
| `children` ✦ | React children, Vue default slot, Svelte `children` snippet | footer under the stats |

## Footer ✦

Children render in a footer under the stats: a note, an action row.
