## API
| Part | Props | Notes |
| --- | --- | --- |
| `AgentCard` | `name, address?, tag?, autopilot?, stats?, seed?` | Card with identicon, secondary tag badge, brand Autopilot badge and stats. |
| `AgentIdenticon` | `seed, size=44` | Token-colored 5x5 grid, deterministic per seed. |
| `raised` | `boolean` | `false` |
