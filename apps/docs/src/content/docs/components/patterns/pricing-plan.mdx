## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. `elevation` is forwarded to the card: `sunken` (-1) a soft inset well, `raised` (+1) the bevel, `floating` (+2) the bevel plus one soft drop. In a layered `ElevationProvider` the card resolves to its role default (raised).

## API

| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| `PricingPlan` | `name` | React `ReactNode`; Vue slot `name` (string prop as fallback); Svelte `string \| Snippet` | required |
|  | `tagline, price, priceNote` | React `ReactNode`; Vue slots `tagline`, `price`, `price-note` (string props as fallback); Svelte `string \| Snippet` | none |
|  | `action` | React `ReactNode`; Vue slot `action`; Svelte `action` snippet. Usually a `Button`; buttons there stretch full width | none |
|  | `features` | React `ReactNode[]`; Vue `string[]`; Svelte `(string \| Snippet)[]` (rich rows: see `feature` below) | none |
|  | `feature ✦` | Vue scoped slot `feature` (`{ feature, index }`); Svelte snippet `feature(text, index)`. React renders any node directly from `features` | the text |
|  | `featuresLead ✦` | Lead row above the features. React `ReactNode`; Vue `string` or slot `features-lead`; Svelte `string \| Snippet` | none |
|  | `elevation` ✦ | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
