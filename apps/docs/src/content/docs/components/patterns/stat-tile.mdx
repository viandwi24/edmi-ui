## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. `elevation` is forwarded to the card: `sunken` (-1) a soft inset well, `raised` (+1) the bevel, `floating` (+2) the bevel plus one soft drop. In a layered `ElevationProvider` the card resolves to its role default (raised).

## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| `StatTile` | `label` / `value` | `ReactNode` (Vue slots `label` / `value`, Svelte `string \| Snippet`) | required |
| | `delta` | `string` (sign sets success/destructive badge) | none |
| | `deltaLabel` | `ReactNode` (Vue `delta-label` slot, Svelte `string \| Snippet`) | none |
| | `trend` | `"up" \| "down"` (overrides the sign) | auto |
| | `meter` | `StatMeter` props | none |
| | `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
| `StatStrip` | `elevation` | forwarded to the card | `"auto"` |
| `StatStripItem` | `label` / `value` | `ReactNode` (Vue slots `label` / `value`, Svelte `string \| number \| Snippet`) | required |
| `StatMeter` | `value` | `number` 0..1 | required |
| | `steps` | `number` | `30` |
| | `zones` | `{ upTo: number; color: string }[]` | green / amber / red |

## ✦ Edmi additions
- `StatMeter` and `StatStrip` / `StatStripItem` are separate exports of the same block.
