## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. `elevation` sets the depth of the bar; `raised` (+1) and `floating` (+2) also raise the brand mark. Pass `elevation` to the call-to-action `Button` yourself (the Svelte `action` snippet receives `{ elevation }` to forward).

## API
| Prop | Type | Default |
| --- | --- | --- |
| `logo` | `ReactNode` | chart mark |
| `name` | `ReactNode` | `"Stockbreak"` |
| `href` | `string` | `"/"` |
| `lead` | `ReactNode` (muted text before `steps`) | none |
| `steps` | `{ label, href }[]` (separated by 1px dividers) | `[]` |
| `links` | `{ label, href }[]` | `[]` |
| `action` | `ReactNode` (usually a `Button`) | none |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Also exported: `SiteHeaderBrand`, `SiteHeaderMark`. Nav hides below `md`.
