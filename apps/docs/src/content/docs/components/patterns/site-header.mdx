## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default. `elevation` sets the depth of the bar; `raised` (+1) and `floating` (+2) also raise the brand mark. Pass `elevation` to the call-to-action `Button` yourself (the Svelte `action` snippet receives `{ elevation }` to forward).

## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| `SiteHeader` | `logo` | `ReactNode` (Vue `logo` slot, Svelte snippet) | chart mark |
| | `name` | `ReactNode` (Vue `name` slot, Svelte `string \| Snippet`) | none |
| | `href` | `string` | `"/"` |
| | `lead` | `ReactNode` muted text before `steps` (Vue `lead` slot, Svelte `string \| Snippet`) | none |
| | `steps` | `{ label, href }[]` (separated by 1px dividers) | `[]` |
| | `links` | `{ label, href }[]` | `[]` |
| | `action` | `ReactNode`, usually a `Button` (Vue `action` slot, Svelte snippet receiving `{ elevation }`) | none |
| | `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
| `SiteHeaderBrand` | `logo`, `name`, `href`, `elevation` | as above; the name is not rendered when empty | |
| `SiteHeaderMark` | `elevation` | raised +1 / floating +2 give the mark the raised face | `"auto"` |

Nav hides below `md`.
