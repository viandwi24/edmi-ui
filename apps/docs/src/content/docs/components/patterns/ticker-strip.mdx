## Raised ✦

Flat by default. Pass `raised` for the one-step 3D look.

<ComponentDemo name="ticker-strip" demo="ticker-strip-raised" />

## API
| Prop | Type | Default |
| --- | --- | --- |
| `items` | `{ symbol, price, change, image?, href? }[]` | required |
| `raised` | `boolean` | `false` |

`change` is a signed string; a leading `-`/`−` renders `--destructive-text`, otherwise `--success-text`.

## ✦ Edmi additions
- Scrolls horizontally when cells do not fit.
