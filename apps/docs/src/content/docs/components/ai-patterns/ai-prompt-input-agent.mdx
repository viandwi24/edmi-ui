## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

The composer plate is an overlay surface: flat by default, floating in layered mode; `sunken` (-1), `raised` (+1) and `floating` (+2) can be set on `PromptInput`.

## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| PromptInputAgent | `agent` | `{ id, name, scope?, color? }` | |
| PromptInputAgentMentions | `agents`, `activeIndex`, `onSelect`, `label` | list that opens above the nearest `relative` ancestor | |
| useAgentMention | `agents`, `value`, `onValueChange`, `onAgentSelect` | returns `{ open, onKeyDown, mentions }` | |

## ✦ Edmi additions
- Put `PromptInputAgent` in `PromptInputHeader`. Typing `@` opens the mention list (arrows, Enter or Tab pick, Escape closes); render it next to `PromptInput`, not inside, because the input group clips overflow.
- Pass `elevation` to `PromptInput` for the plate depth; the muted shell is a class on the form (`[&_[data-slot=input-group]]:bg-muted`).
