## API
| Prop | Type | Default |
| --- | --- | --- |
| `seed` | `string` (agent id: same seed, same mark) | |
| `color` | `chart-1` to `chart-5` or any CSS color | picked from the seed |
| `size` | `number` (px) | `40` |
| `tile` | `boolean` (muted rounded square behind the mark) | `true` |
| `label` | `string` (accessible name; decorative when omitted) | |

## ✦ Edmi additions
- The mark is a 3 by 5 grid mirrored to 5 by 5, so it stays recognisable at 20px. Use it only where several agents appear.
