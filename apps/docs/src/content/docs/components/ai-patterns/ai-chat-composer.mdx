## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

The composer plate is an overlay surface: flat by default, floating in layered mode. `sunken` (-1) is a soft inset, `raised` (+1) a bevel and `floating` (+2) a bevel with a soft drop; the send button follows the Button rules.

## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| ChatComposer | `onSubmit` | `(message, event) => void` | required |
| ChatComposer | `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
| ChatComposer | `placeholder`, `status`, `onStop` | `string`, `ChatStatus`, `() => void` | `Reply` |
| ChatComposer | `onAttach`, `onSpeech` | `() => void` (button hidden when omitted) | |
| ChatComposer | `disclaimer` | `ReactNode` (Vue: `disclaimer` slot, Svelte: `string \| Snippet`) | |
| ChatComposer | `models`, `model`, `defaultModel`, `onModelChange` | `{ id, label }[]`, ids (Vue: `v-model:model`, Svelte: `bind:model` plus `onModelChange`) | first option |
| ChatComposer | `efforts`, `effort`, `defaultEffort`, `onEffortChange` | same shape (`v-model:effort`, `bind:effort`) | first option |
| ChatComposer | `modes`, `mode`, `defaultMode`, `onModeChange` | same shape (`v-model:mode`, `bind:mode`) | first option |

## ✦ Edmi additions
