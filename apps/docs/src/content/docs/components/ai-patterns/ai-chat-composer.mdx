## Elevation ✦

The composer plate is an overlay surface: flat by default, floating in layered mode. `sunken` (-1) is a soft inset, `raised` (+1) a bevel and `floating` (+2) a bevel with a soft drop; the send button follows the Button rules.

## API
| Prop | Type | Default |
| --- | --- | --- |
| `onSubmit` | `(message, event) => void` | required |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
| `placeholder`, `status`, `onStop` | `string`, `ChatStatus`, `() => void` | `Reply` |
| `onAttach`, `onSpeech` | `() => void` (button hidden when omitted) | |
| `disclaimer` | `ReactNode` | |
| `models`, `model`, `defaultModel`, `onModelChange` | `{ id, label }[]`, ids | first option |
| `efforts`, `effort`, `defaultEffort`, `onEffortChange` | same shape | first option |
| `modes`, `mode`, `defaultMode`, `onModeChange` | same shape | first option |

## ✦ Edmi additions
- A one-line field with an enter hint, and a quiet footer row below it (not inside the field): attach, speech, disclaimer, model with effort, mode.
