## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Flat by default and a surface in layered mode. `sunken` (-1) is a soft inset, `raised` (+1) a bevel and `floating` (+2) a bevel with a soft drop. The paper inside never changes.

## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| ArtifactViewer | `elevation`, Card props | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |
| ArtifactViewerTitle | `format` | `ReactNode` (shown after the title in mono) | |
| ArtifactViewerAction | `label` | `string` (tooltip and accessible name) | |
| ArtifactViewerOpenIn / Download / Expand / Close | `label`, Button props | `string` | |
| ArtifactViewerContent | | scroll area on `--muted` | |
| ArtifactViewerPaper | | white page, same in every mode | |

In Vue `ReactNode` props are slots of the same name (the string prop stays as a fallback); in Svelte they accept `string | Snippet`.

## ✦ Edmi additions
- Documents render as paper (white page) on the muted body in light and dark mode. The paper colours are fixed by design (a document renders as paper in every mode), so they are literal colours and not tokens.
