## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| ModelSelector | `Dialog` props (`open`, `onOpenChange`) | | |
| ModelSelectorTrigger | `render` | element, e.g. `<Button variant="outline" />` | |
| ModelSelectorContent | `title` | `ReactNode` (screen reader) | `Model Selector` |
| ModelSelectorLogo | `provider` | models.dev provider id | |
| ModelSelectorInput/List/Empty/Group/Item/Shortcut/Separator/Name/LogoGroup, ModelSelectorDialog | | | |

Logos load from `https://models.dev/logos/<provider>.svg`.

## ✦ Edmi additions
- The popup is the Edmi dialog with the command palette inside (no close button, search first).
