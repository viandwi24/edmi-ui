## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| Conversation | `autoScroll` | `boolean` | `true` |
| ConversationContent | | `MessageScrollerContent` props | |
| ConversationItem | `messageId`, `scrollAnchor` | `string`, `boolean` | |
| ConversationEmptyState | `title`, `description`, `icon`, `variant` | `ReactNode`, `default \| home` | `default` |
| ConversationScrollButton | | `MessageScrollerButton` props | |
| ConversationDownload | `messages`, `filename`, `formatMessage` | `UIMessage[]`, `string`, `fn` | `conversation.md` |

Wrap each turn in `ConversationItem` so the scroller can anchor it; the container needs a height.

## Vue and Svelte
- `ConversationEmptyState` icon: React `icon` prop, Vue `#icon` slot, Svelte `icon` snippet.

## ✦ Edmi additions
- `ConversationEmptyState variant="home"`: greeting heading and subtitle with a `children` slot for the composer and suggestions.
- The scroll button is a round outline icon button; the stick-to-bottom logic comes from `message-scroller`, not `use-stick-to-bottom`.
