## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| Message | `from` | `user \| assistant \| system` | |
| MessageContent | `variant` | `Bubble` variant | `secondary` (user), `ghost` (assistant) |
| MessageResponse | `Streamdown` props | markdown string as `children` | |
| MessageAction | `tooltip`, `label` | `string` | |
| MessageBranch | `defaultBranch`, `onBranchChange` | `number`, `fn` | `0` |
| MessageToolbar, MessageActions, MessageBranchSelector/Previous/Next/Page | | | |
| MessageAvatar, MessageHeader | | opt-in (multi-agent) | |

`MessageResponse` uses [Streamdown](https://streamdown.ai); add `@source "../node_modules/streamdown/dist/*.js";` to your Tailwind CSS so its classes are generated.

## Vue and Svelte
- `MessageResponse` takes the markdown as `content` (Vue also accepts the default slot text, Svelte the `content` prop only). Vue renders with `vue-stream-markdown`, Svelte with `svelte-streamdown`; the typography above is applied through each library's own hooks, so code-block styling follows the library defaults.
- `MessageBranchContent`: every direct child is one branch (React `children`, Vue slot children, Svelte `{#each}` children). Svelte counts the rendered children and hides all but the current one.
- Branch change: React `onBranchChange`, Vue `@branch-change`, Svelte `onBranchChange`.

## ✦ Edmi additions
- No assistant avatar by default: the response is full width on the left, the user turn is a secondary bubble on the right.
- Status and shimmer text goes inside `MessageContent` (a ghost bubble) so its first line aligns like any message.
- `MessageResponse` typography: 15px / 1.65, 600 lead-ins, h1-h3 22/18/16, inline code in mono 12.5 on `--muted` with `--destructive-text`, links `--info-text` underlined, 3px `--border` quote rule, 22px list indent, max ~68ch.
- `MessageAvatar` + `MessageHeader` for multi-agent chats: the avatar aligns to the name line.
