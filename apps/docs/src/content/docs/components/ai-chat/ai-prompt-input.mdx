## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| PromptInput | `onSubmit`, `accept`, `multiple`, `maxFiles`, `maxFileSize`, `globalDrop`, `onError` | `(message, event) => void`, ... | |
| PromptInput | `raised` | `boolean` | `false` |
| PromptInputTextarea | `InputGroupTextarea` props | Enter submits, Shift+Enter newline | |
| PromptInputSubmit | `status`, `onStop` | `ready \| submitted \| streaming \| error` | |
| PromptInputProvider | `initialInput` | `string` | lifts text and attachments out of the form |
| PromptInputHeader/Body/Footer/Tools/Button/ActionMenu*/Select*/Command*/HoverCard* | | | |

Hooks: `usePromptInputAttachments`, `usePromptInputController`, `useProviderAttachments`, `usePromptInputReferencedSources`.

## ✦ Edmi additions
- The send icon follows the chat status: arrow up (ready), spinner (submitted), stop (streaming, with `onStop`), x on destructive (error).
- `raised` applies to the submit button only; the composer shell stays flat.
- Focus ring, 16px radius and `--card` fill come from the Edmi tokens.
