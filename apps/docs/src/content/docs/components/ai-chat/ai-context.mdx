## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| Context | `maxTokens`, `usedTokens`, `usage`, `modelId` | `number`, `number`, `LanguageModelUsage`, `string` | |
| ContextTrigger, ContextContent, ContextContentHeader/Body/Footer | | | |
| ContextInputUsage, ContextOutputUsage, ContextReasoningUsage, ContextCacheUsage | | | |

`usage` is the AI SDK v7 `LanguageModelUsage` (`outputTokenDetails.reasoningTokens`, `inputTokenDetails.cacheReadTokens`).

## Vue and Svelte
- `ContextTrigger` renders a ghost button with the ring and percentage; pass your own trigger with `render` (React), the default slot (Vue) or a `child` snippet (Svelte).

## ✦ Edmi additions
- The trigger is a small `--brand` ring plus the percentage; at 90% and above the percentage turns `--warning-text`.
- The progress bar is `Progress variant="brand"`; the footer sits on `--muted`.
