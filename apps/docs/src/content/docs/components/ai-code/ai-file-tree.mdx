## ✦ Edmi additions
- Rows are 28px with an `accent` fill for the selected path; folder icons use `chart-3`; no connector lines.
- Vue: `v-model:expanded` and the `select` event; Svelte: `bind:expanded` and `onSelect`. `FileTreeFile` takes an `icon` slot (Vue) or `icon` snippet (Svelte).
