## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| Artifact | `raised` | `boolean` | `false` |
| ArtifactAction | `tooltip`, `label`, `icon` | `string`, `string`, `ReactNode` | |
| ArtifactClose | `Button` props | | `variant="ghost"` |
| ArtifactContent | `className` | `string` | no padding |

## ✦ Edmi additions
- `raised`: the container gets the one-step 3D look.
- `ArtifactContent` has no padding by default so code blocks and images run edge to edge; add `p-4` for prose.
- `ArtifactAction` takes the icon as a node (`icon={<IconPlaceholder … />}`) instead of a component.
- Vue and Svelte: the action icon goes in the default slot / children instead of an `icon` prop.
