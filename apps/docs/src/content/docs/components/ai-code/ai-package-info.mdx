## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| PackageInfo | `name`, `currentVersion`, `newVersion` | `string` | |
| PackageInfo | `changeType` | `major \| minor \| patch \| added \| removed` | |
| PackageInfoDependency | `name`, `version` | `string` | |

## ✦ Edmi additions
- Change types map to badge variants: major `destructive`, minor `warning`, patch `success`, added `info`, removed `secondary`.
- With only `newVersion` (added) the version reads `→ 6.0.30`.
