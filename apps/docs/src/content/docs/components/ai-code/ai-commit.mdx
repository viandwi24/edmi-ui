| --- | --- | --- | --- |

## ✦ Edmi additions
- `CommitFilesToggle`: the "N files changed" row that opens the file list (the header itself no longer toggles).
- Relative timestamps resolve to minutes and hours, not only days.
- Status badges use the soft success, warning, info and destructive variants; additions and deletions always render (`+0`, `−0`).
