Derived from [Vercel AI Elements](https://elements.ai-sdk.dev/components/code-block) (Apache-2.0), restyled for Edmi UI. The canonical code block of the kit: the body sits on `card`, the header on `muted`. Built on `button` and `select`; highlighting uses Shiki's CSS-variables theme mapped onto chart tokens (keyword `chart-2`, string `success-text`, number `chart-3`, function `chart-4`, comment `muted-foreground`), so it follows mode, base and theme.
