## API
| Prop | Type | Default |
| --- | --- | --- |
| `Item variant` | `default \| outline \| muted` | `default` |
| `Item size` | `default \| sm \| xs` | `default` |
| `Item render` | `ReactElement` | none (Base UI, replaces `asChild`) |
| `ItemMedia variant` | `default \| icon \| image` | `default` |

Parts: `ItemGroup`, `ItemSeparator`, `Item`, `ItemMedia`, `ItemContent`, `ItemTitle`, `ItemDescription`, `ItemActions`, `ItemHeader`, `ItemFooter`.

## ✦ Edmi additions
- Icon media is a bordered 38px tile on `--muted`; outline items sit on `--card`.
