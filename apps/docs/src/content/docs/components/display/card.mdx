## Elevation ✦

Flat by default (border only). `sunken` (-1) turns the card into a soft inset well, `raised` (+1) adds the bevel (inner rim, top highlight, dark hairline) and `floating` (+2) the bevel plus one soft drop. A card inside a raised or floating surface resolves flat (no bevel on bevel).

## API
| Prop | Type | Default |
| --- | --- | --- |
| `size` | `default \| sm` | `default` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Parts: `Card`, `CardHeader`, `CardTitle`, `CardDescription`, `CardAction`, `CardContent`, `CardFooter`.

## ✦ Edmi additions
- Flat (border only); `elevation` adds the bevel / drop (surface role: raised in layered mode). Footer on a muted tint.
- Publishes its level to nested cards, which drop to flat.
