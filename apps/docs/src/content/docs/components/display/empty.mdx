## Elevation ✦

Flat by default. On `EmptyMedia variant="icon"`, `raised` (+1) and `floating` (+2) make the media tile rise.

<ComponentDemo name="empty" demo="empty-raised" />

## API
| Prop | Type | Default |
| --- | --- | --- |
| `EmptyMedia variant` | `default \| icon` | `default` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Outline = dashed: add `border border-input` to `Empty` (the dashed style is built in).

Parts: `Empty`, `EmptyHeader`, `EmptyMedia`, `EmptyTitle`, `EmptyDescription`, `EmptyContent`.

## ✦ Edmi additions
- Icon media is a 48px tile (`--card`, 1px border); `elevation` raises it with the bevel.
