## Elevation ✦

Flat by default. `raised` (+1) bevels the body plate, `floating` (+2) also gives the shell the soft drop and `sunken` (-1) turns the shell into a well. The shell itself is level 0 and never rises on its own.

<ComponentDemo name="inset-panel" demo="inset-panel-raised" />

## API
| Prop | Type | Default |
| --- | --- | --- |
| `InsetPanelBody fade` | `boolean` | `false` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Parts: `InsetPanel`, `InsetPanelHeader`, `InsetPanelBody`, `InsetPanelFooter`.

## ✦ Edmi additions
- Whole component is an Edmi addition (DESIGN §4.8): the body is a `--card` plate inset 2px from the shell (left, right, bottom) with its own full radius; with a footer the body keeps a 0 bottom gap and the footer sits on the shell without a divider.
