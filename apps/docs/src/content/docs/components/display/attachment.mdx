## API
| Prop | Type | Default |
| --- | --- | --- |
| `state` | `idle \| uploading \| processing \| error \| done` | `done` |
| `size` | `default \| sm \| xs` | `default` |
| `orientation` | `horizontal \| vertical` | `horizontal` |
| `AttachmentMedia variant` | `icon \| image` | `icon` |

Parts: `Attachment`, `AttachmentGroup`, `AttachmentMedia`, `AttachmentContent`, `AttachmentTitle`, `AttachmentDescription`, `AttachmentActions`, `AttachmentAction`, `AttachmentTrigger`.
