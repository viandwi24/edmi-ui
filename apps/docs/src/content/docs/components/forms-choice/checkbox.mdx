## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Only the checked (and indeterminate) box rises: `raised` (+1) or `floating` (+2) gives it a bevel. The unchecked box stays flat.

## API
Built on Base UI `Checkbox`. Same props as shadcn.

| Prop | Type | Default |
| --- | --- | --- |
| `checked` / `defaultChecked` | `boolean` | `false` |
| `indeterminate` | `boolean` | `false` |
| `onCheckedChange` | `(checked: boolean, event) => void` | - |
| `disabled` | `boolean` | `false` |
| `aria-invalid` | `boolean` | - |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

## ✦ Edmi additions
- Checked and indeterminate use a solid `--primary` fill (`elevation` raises the checked box) with a check/minus icon.
