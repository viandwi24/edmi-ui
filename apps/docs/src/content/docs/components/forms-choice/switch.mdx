## API
Built on Base UI `Switch`.

| Prop | Type | Default |
| --- | --- | --- |
| `size` | `"sm" \| "default"` | `"default"` |
| `checked` / `defaultChecked` | `boolean` | `false` |
| `onCheckedChange` | `(checked: boolean, event) => void` | - |
| `disabled` | `boolean` | `false` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

## ✦ Edmi additions
- Checked track uses `--brand` (not `--primary`) so live settings read as active.
