## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

Only the thumbs rise (`raised` +1 or `floating` +2); the track and range never get a bevel.

## API
Built on Base UI `Slider`.

| Prop | Type | Default |
| --- | --- | --- |
| `value` / `defaultValue` | `number[]` | - |
| `min` / `max` / `step` | `number` | `0` / `100` / `1` |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |
| `onValueChange` | `(value: number[], event) => void` | - |
| `disabled` | `boolean` | `false` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

## ✦ Edmi additions
- Brand-colored range and a round thumb (`elevation` raises the thumbs); focus shows a soft ring.
