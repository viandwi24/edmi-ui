## API

| --- | --- | --- | --- |
| WebPreview | `defaultUrl`, `onUrlChange`, `defaultConsoleOpen` | `string`, `(url) => void`, `boolean` | `""`, `false` |

| WebPreviewNavigation, Url | | | |

## ✦ Edmi additions
- The URL field is mono with a lock icon; navigation buttons are `ghost` icon buttons (open in new tab and fullscreen are yours to add as buttons).
- `defaultConsoleOpen` starts the console expanded.
- The body is a sandboxed `iframe`; pass `loading` to cover it while the preview is generated.
