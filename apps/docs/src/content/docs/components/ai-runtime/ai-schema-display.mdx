## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| SchemaDisplay | `method`, `path`, `description` | `GET \| POST \| PUT \| PATCH \| DELETE`, `string`, `string` | |
| SchemaDisplay | `parameters`, `requestBody`, `responseBody` | `SchemaParameter[]`, `SchemaProperty[]`, `SchemaProperty[]` | |
| SchemaDisplayProperty | `name`, `type`, `required`, `properties`, `items`, `depth` | recursive | `0` |
| SchemaDisplayHeader, Method, Path, Description, Content, Parameters, Parameter, Request, Response, Example | | | |

## ✦ Edmi additions
- Method colors use solid soft tokens: GET `--success`, POST `--info`, PUT and PATCH `--warning`, DELETE `--destructive`.
- `{param}` segments of the path are highlighted in `--chart-2` (rendered as elements, not HTML).
