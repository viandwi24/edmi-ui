## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| StackTrace | `trace`, `open`, `defaultOpen`, `onOpenChange` | `string`, `boolean`, `boolean`, `(open) => void` | `false` |

| StackTraceHeader, Error, ErrorType, ErrorMessage, Actions, CopyButton, ExpandButton | | | |

## ✦ Edmi additions
- Frames outside your code (`node_modules`, `node:`, `internal/`) are dimmed; your files are underlined links when `onFilePathClick` is set.
- The error type uses `--destructive-text` with a bug icon, as on the board.
