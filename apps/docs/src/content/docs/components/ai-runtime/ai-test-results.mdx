## API
| Part | Prop | Type | Default |
| --- | --- | --- | --- |
| TestResults | `summary` | `{ passed, failed, skipped, total, duration? }` | |
| TestSuite | `name`, `status` | `string`, `passed \| failed \| skipped \| running` | |
| Test | `name`, `status`, `duration` | `string`, status, `number` | |
| TestResultsHeader, Summary, Duration, Progress, Content, TestSuiteName, TestSuiteStats, TestSuiteContent, TestError, TestErrorMessage, TestErrorStack | | | |

## ✦ Edmi additions
- Summary badges and the progress bar use `--success`, `--destructive`, `--warning` and `--info`; a running test shows a spinner.
- Durations are mono.
