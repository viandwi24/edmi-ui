## Anatomy
```tsx
const table = useTable({ features, data, columns }) // TanStack Table v9
<DataTable columns data />            // toolbar + table + pagination
  <DataTableViewOptions />            // column visibility
  <DataTableColumnHeader />           // sort / hide
  <DataTablePagination />             // rows per page, page nav, selection count
  <DataTableFacetedFilter /> ✦        // dashed "+ Status" filters
  <DataTableRowActions /> ✦           // ghost "…" + DropdownMenu
```

Declare the features once in `data-table-features.ts` (v9 is feature-based, unused features are tree-shaken) and pass `typeof features` as the first generic to `ColumnDef`, `Column` and `Table`.

## Elevation ✦

See the [Elevation guide](/edmi-ui/getting-started/elevation/) for the levels, roles and layered mode.

The table container stays flat. `elevation` sets the depth of the toolbar and pagination controls: filter input, faceted filters, view options, page size select and page buttons (`raised` +1, `floating` +2, `sunken` -1 for the fields).

## API
| Prop | Type | Default |
| --- | --- | --- |
| `DataTable columns` | `ColumnDef<DataTableFeatures, TData, any>[]` | required |
| `DataTable data` | `TData[]` | required |
| `DataTable filterColumn` | `string` (column id) | none (no input) |
| `DataTable facetedFilters` ✦ | `{ column, title, options? }[]` | none |
| `DataTable pageSize` | `number` | `10` |
| `DataTableColumnHeader numeric` ✦ | `boolean` | `false` |
| `DataTablePagination pageSizes` | `number[]` (the current page size is added if missing) | `[10, 20, 30, 40, 50]` |
| `elevation` | `"auto" \| "sunken" \| "flat" \| "raised" \| "floating"` | `"auto"` |

Requires `@tanstack/react-table` (v9), and the `table`, `button`, `input`, `checkbox`, `select`, `dropdown-menu` and `badge` items.

## ✦ Edmi additions
- Table sits in a bordered card surface (always flat); selected rows get a soft brand tint.
- Numbers are mono and right-aligned (`numeric`), deltas use `success`/`destructive` badges.
- Dashed faceted filter buttons and `DataTableRowActions` match the kit board.

## Vue / Svelte differences
- **Vue** and **Svelte** include an extra `TableEmpty` part for the no-results row.
