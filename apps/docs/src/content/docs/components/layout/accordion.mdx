## API
| Prop | Type | Default |
| --- | --- | --- |
| `multiple` | `boolean` | `false` |
| `defaultValue` / `value` | `string[]` | `[]` |
| `variant` ✦ | `"default" \| "card"` | `"default"` |
| `AccordionItem value` | `string` | — |

Anatomy: `Accordion`, `AccordionItem`, `AccordionTrigger`, `AccordionContent`.

## ✦ Edmi additions
- `variant="card"`: items inside a bordered card with hairline dividers.

## Vue / Svelte differences
- **Vue** (Reka UI) and **Svelte** (Bits UI): `type="single" | "multiple"` (plus `collapsible`) replaces React's `multiple` boolean.
- Svelte: the root `value` is a `string` when `type="single"` and a `string[]` when `type="multiple"`.
