## API
| Export | Notes |
| --- | --- |
| `DirectionProvider direction` | `"ltr" \| "rtl"` — also set `dir` on `<html>` |
| `useDirection()` | returns the current direction |

## ✦ Edmi additions
None — re-export of Base UI's direction provider.

## Vue / Svelte differences
- **Vue**: `DirectionProvider direction="rtl"`; `useDirection()` returns a `ComputedRef`.
- **Svelte**: `DirectionProvider direction="rtl"`; `useDirection()` returns `{ current }`.
