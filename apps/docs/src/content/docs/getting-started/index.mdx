Edmi (EDitorial MInimalist) restyles the shadcn component set in three frameworks from one set of tokens.
Item names, anatomy and props match the stock shadcn ports, so `add @edmi-ui/<name> --overwrite` is a drop-in
restyle. Components are copied into your project: you own the code.

| Framework | Primitives | Stock library |
| --- | --- | --- |
| React | Base UI | shadcn/ui |
| Vue | Reka UI | shadcn-vue |
| Svelte | Bits UI | shadcn-svelte |

## Where to start

1. **[Install with React](/edmi-ui/getting-started/installation/react/)**, [Vue](/edmi-ui/getting-started/installation/vue/) or [Svelte](/edmi-ui/getting-started/installation/svelte/): add the registry and the theme.
2. **[Theming](/edmi-ui/getting-started/theming/)**: tokens, base color, theme, radius and dark mode. Try them live on the [Themes](/edmi-ui/themes/) page.
3. **[Elevation](/edmi-ui/getting-started/elevation/)**: how depth works (sunken, flat, raised, floating), the layered mode and the philosophy behind it.
4. **[Rules](/edmi-ui/getting-started/rules/)**: the design decisions behind every component.
5. **[Components](/edmi-ui/components/)**: every UI and AI item with a live demo and its code.

Each item is a registry JSON that the shadcn CLI of your framework can install. Pick the package manager in any
install command; the choice is remembered across the site.
