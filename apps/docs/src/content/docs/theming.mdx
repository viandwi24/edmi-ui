Tokens are CSS variables (OKLCH with a hex fallback) and share names with shadcn. Load them with
`@edmi/tokens/tokens.css` and map them to Tailwind v4 with `@edmi/tokens/theme.css`.

```css
@import "tailwindcss";
@import "@edmi/tokens/tokens.css";
@import "@edmi/tokens/theme.css";
```

Type: **Instrument Sans** for UI text, **JetBrains Mono** for every number, **Sora 600** for the wordmark only.

## Flat by default, `raised` opt-in

The shadow tokens (`shadow-btn-*`, `shadow-card`, `shadow-pop`, `shadow-dialog`) are only used when a component is rendered with `raised`. Without it every component is flat: a solid fill, a 1px border and no lip.

Use it per component, never globally:

```tsx
<Button raised>Get started</Button>
<TabsList raised variant="pills">…</TabsList>
<Card raised>…</Card>
```

Vue and Svelte take the same boolean prop (`<Button raised>`, `<Tabs.List raised variant="pills">`). The landing page toggle flips every showcase component between flat and raised. See each framework's getting-started page for the full list of components that accept `raised`.
